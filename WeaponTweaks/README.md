# Weapon Tweaks

Overhaul-only. Small fixes to how some weapons behave.

- **Burnzooka:** the rocket explodes on the first enemy it hits. In vanilla it flies through enemies and only explodes when it reaches a wall or the end of its range, so the explosion and napalm only landed on enemies standing against a wall.

Turn it off under Mod Options > Turn Sub-Mods On/Off > Weapon Tweaks (restart to apply). In multiplayer, use the same switch as the host.
